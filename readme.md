# StudySync

**Live Demo**: [https://buildsbyaman-studysync.vercel.app/](https://buildsbyaman-studysync.vercel.app/)

StudySync is a static frontend project containing a small educational website built with HTML, CSS, and JavaScript.

Contents

- `index.html` — main entry page
- `style.css` — site styles
- `script.js` — client-side JavaScript
- `assests/` — images and other static assets
- `components/` — partial pages / component examples (Blogs, ContactUS, Features, Pricing, TermsServices)
- `vercel.json` — deployment config (if used)
